# Zadanie 1 — przypomnienie podstaw programowania

Dwie aplikacje konsolowe (Python i C#). W każdej: **1** — kalkulator dwóch liczb, **2** — konwerter Celsjusz/Fahrenheit, **3** — średnia ocen i informacja o zaliczeniu, **0** — wyjście.

## Uruchomienie z katalogu projektu

- Python 3: `python3 python/main.py`
- C# (.NET 8 SDK): `dotnet run --project csharp/Zadanie1.csproj`

Liczby dziesiętne wpisuj z kropką. W ćwiczeniu 3 najpierw podaj liczbę ocen, potem oceny od 1 do 6. Przykład: liczba ocen **4**, oceny **5, 3, 4, 2** → **3.50**, uczeń zdał. Próg zaliczenia: **3.0**.
